# Planejamento de viagem — Europa 2027

Site estático em português criado a partir do guia visual fornecido. Não precisa de servidor ou dependências para funcionar.

## Abrir localmente

Abra `index.html` em um navegador. As atrações salvas ficam no armazenamento local desse navegador.

## Publicar com GitHub Pages

1. Crie um repositório público no GitHub e envie estes arquivos para a branch `main`.
2. Em **Settings → Pages**, escolha **Deploy from a branch**, selecione `main` e a pasta `/ (root)`.
3. Após a publicação, o GitHub mostrará o endereço do site nessa mesma página.

O site usa Google Fonts e fotografias hospedadas em serviços externos; a exibição dessas imagens depende desses serviços.
